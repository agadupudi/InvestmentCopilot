# Backend — Investment Co-Pilot API

FastAPI service that owns holdings, fetches live quotes, and computes portfolio P&L.

## Stack

| Concern | Choice |
|---|---|
| Web framework | FastAPI 0.115+ |
| ASGI server | uvicorn[standard] (uvloop + httptools) |
| ORM | SQLAlchemy 2.x (async) |
| DB driver | asyncpg |
| Migrations | Alembic (async template) |
| Validation/config | Pydantic v2 + pydantic-settings |
| Cache | redis-py (asyncio) |
| Outbound HTTP | httpx |
| Market data | yfinance |
| Lint | ruff |
| Tests | pytest + pytest-asyncio |
| Types | mypy (strict) |
| Toolchain | uv |

## First-time setup

From the repo root, make sure `docker compose up -d` is running so Postgres + Redis are available.

```bash
cd backend
uv sync                            # creates .venv, installs deps from lock
uv run alembic upgrade head        # apply migrations
```

## Run the dev server

```bash
uv run uvicorn app.main:app --reload
```

## Environment

Copy `.env.example` → `.env` if you want to override defaults. All settings are read by `app/core/config.py` via `pydantic-settings`.

| Var | Default | Notes |
|---|---|---|
| `ENVIRONMENT` | `local` | Free-form label |
| `DEBUG` | `true` | Enables SQLAlchemy echo + verbose logging |
| `DATABASE_URL` | `postgresql+asyncpg://copilot:copilot@localhost:5432/copilot` | Must use `+asyncpg` driver |
| `REDIS_URL` | `redis://localhost:6379/0` | |
| `CORS_ORIGINS` | `["http://localhost:3000"]` | JSON list — frontend origins allowed by CORS |
| `QUOTE_CACHE_TTL_SECONDS` | `60` | yfinance cache TTL in Redis |

## Migrations

Schema changes follow the standard Alembic flow. Models live in `app/models/`; `alembic/env.py` imports them so autogenerate works.

```bash
# 1. Modify a SQLAlchemy model in app/models/
# 2. Generate a migration
uv run alembic revision --autogenerate -m "describe the change"

# 3. Inspect the generated file in alembic/versions/

# 4. Apply
uv run alembic upgrade head

# Rollback one step
uv run alembic downgrade -1

# Show current revision
uv run alembic current
```

> **Always inspect autogenerated migrations before committing.** Alembic can miss enum changes, server defaults, and check constraints.

## How quotes work

`app/services/quotes.py`:
1. Caller asks for a symbol (e.g. `AAPL`).
2. We check Redis at `quote:AAPL`. If a cached price exists → return it.
3. Otherwise, run `yfinance.Ticker(symbol).fast_info.last_price` in a worker thread (yfinance is sync).
4. Store result in Redis with TTL = `QUOTE_CACHE_TTL_SECONDS` (default 60s).
5. Return the price.

`get_prices(symbols)` parallelizes per-symbol calls with `asyncio.gather`.

> **Phase 2 plan:** replace yfinance with WebSocket streaming from a paid feed (Polygon/Finnhub) and publish updates over Redis pub/sub to the frontend via FastAPI WebSocket.

## How P&L is computed

`app/services/holdings.py::list_holdings_with_quotes`:

```
market_value     = last_price × quantity
cost_total       = cost_basis × quantity
unrealized_pnl   = market_value - cost_total
unrealized_pnl%  = (unrealized_pnl / cost_total) × 100
```

All math uses Python `Decimal` to avoid floating-point drift on currency.

## Common pitfalls

- **`asyncpg` driver is required** in the URL (`postgresql+asyncpg://...`). Plain `postgresql://...` will use psycopg2 and fail with the async engine.
- **uv sync** must run inside the `backend/` directory — it uses the local `pyproject.toml`.
- **First `uv sync` is slow** (downloads Python 3.12 + ~50 packages). Subsequent runs are instant.
- **yfinance can rate-limit you** if you hammer it. The 60s Redis cache is intentional.
