Day-to-day commands. Skim this when you forget the exact incantation.

## One-time setup

```bash
# Install OrbStack (one time)
brew install --cask orbstack
open -a OrbStack                  # finish setup in the GUI

# Install uv (one time)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Verify
docker --version
docker compose version
uv --version
node --version            # must be >= 20
```

> If `docker` isn't found in a fresh shell, OrbStack's PATH hasn't been wired in yet. Restart the terminal (or run `export PATH="$HOME/.orbstack/bin:$PATH"`).

## Start everything

```bash
# Terminal 1 — infra
docker compose up -d

# Terminal 2 — backend
cd backend
uv sync                                   # first time only
uv run alembic upgrade head               # first time / after schema changes
uv run uvicorn app.main:app --reload

# Terminal 3 — frontend
cd frontend
npm install                               # first time only
npm run dev
```

Open http://localhost:3000.

---

## Stop everything

```bash
# Ctrl-C the backend and frontend processes, then:
docker compose down                       # keep volumes
docker compose down -v                    # wipe DB + Redis state
```

## Backend

| Task | Command |
|---|---|
| Install/update deps | `uv sync` |
| Add a runtime dep | `uv add <pkg>` |
| Add a dev-only dep | `uv add --dev <pkg>` |
| Run dev server | `uv run uvicorn app.main:app --reload` |
| Run a one-off Python | `uv run python -c "..."` |
| Open a venv shell | `uv run bash` (or activate `.venv/bin/activate`) |
| Lint | `uv run ruff check .` |
| Lint + autofix | `uv run ruff check --fix .` |
| Format | `uv run ruff format .` |
| Type check | `uv run mypy app` |
| Run tests | `uv run pytest` |
| Run one test | `uv run pytest tests/test_health.py::test_health_endpoint_responds` |

### Migrations

| Task | Command |
|---|---|
| Generate migration from model changes | `uv run alembic revision --autogenerate -m "msg"` |
| Apply all pending | `uv run alembic upgrade head` |
| Roll back one | `uv run alembic downgrade -1` |
| Show current version | `uv run alembic current` |
| Show full history | `uv run alembic history` |

> Always read the autogenerated SQL/Python before applying — autogenerate misses some changes (enums, server defaults, complex constraints).

### Database inspection

```bash
# psql shell into the running container
docker exec -it ic-postgres psql -U copilot -d copilot

# Quick query from the host
docker exec -i ic-postgres psql -U copilot -d copilot -c 'SELECT * FROM holdings;'

# Reset DB to a clean slate
docker compose down -v                    # nukes volumes
docker compose up -d
cd backend && uv run alembic upgrade head
```

### Redis inspection

```bash
docker exec -it ic-redis redis-cli

# In the redis shell:
KEYS quote:*
GET quote:AAPL
TTL quote:AAPL
```

## Project conventions

- **Python:** ruff handles both lint and format. Line length 100. Target Python 3.12.
- **TypeScript:** ESLint flat config. No formatting tool yet (Prettier is implicit through ESLint defaults).
- **Commits:** prefer small, focused commits. Use the personal git identity (auto-applies in `~/Private/`).
- **Migrations:** one model change = one migration. Don't squash unless you understand the implications.
- **Decimal money:** never use `float` for currency on the backend.
- **Decimal display:** numbers come over the wire as JSON strings. Convert with `Number(...)` only at render time.

## Where to look first when something's off

- API not responding → check `docker compose ps` and the uvicorn terminal.
- Frontend blank or broken → check the browser DevTools Console; check the `npm run dev` terminal.
- Migration failing → confirm Postgres is actually running (`docker compose ps`) and `DATABASE_URL` matches.
- Quotes return null → yfinance might be rate limiting; wait 60s and retry, or try a more liquid symbol.

For a longer list of common errors and fixes, see [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md).
